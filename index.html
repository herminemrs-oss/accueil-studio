Méthode officielle

Activer l’accueil
sans risquer le ban.

  1. Compte professionnel

    Instagram Business ou Creator, lié à une Page Facebook. Sans ça, ni Business Suite ni Messaging API.

  2. Meta Business Suite

    Va sur business.facebook.com → Inbox → Automations.

  3. Réponse instantanée

    Active Instant Reply, coche Instagram (et Messenger). Colle le texte composé ici.

  4. Message d’accueil natif

    Sur certains comptes : Instagram → Réglages → Compte professionnel → Message d’accueil.

  5. Commentaire → DM

    Dans Automations, « Comment to message » : un mot-clé sur un post déclenche un message privé.

  6. App développeur (avancé)

    API officielle uniquement : app Meta, revue, webhooks, permission instagram_manage_messages, divulgation bot, chemin vers un humain. Pas de DM à froid aux nouveaux abonnés via l’API publique.
